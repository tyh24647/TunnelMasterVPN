# Primary technical references

Consulted 2026-10-06; recheck requirements before release.

- Apple App Review Guidelines, especially 5.4 VPN Apps and 4.8 login services: https://developer.apple.com/app-store/review/guidelines/
- Native IKEv2 API: https://developer.apple.com/documentation/networkextension/nevpnprotocolikev2
- IPv4 route exclusions: https://developer.apple.com/documentation/networkextension/neipv4settings/excludedroutes
- Subscription setup: https://developer.apple.com/help/app-store-connect/manage-subscriptions/offer-auto-renewable-subscriptions/
- Introductory offers: https://developer.apple.com/help/app-store-connect/manage-subscriptions/set-up-introductory-offers-for-auto-renewable-subscriptions
- Family Sharing: https://developer.apple.com/documentation/storekit/supporting-family-sharing-in-your-app
- Family Sharing configuration: https://developer.apple.com/help/app-store-connect/configure-in-app-purchase-settings/turn-on-family-sharing-for-in-app-purchases/
- WireGuard Apple source mirror: https://github.com/WireGuard/wireguard-apple (pinned source commit recorded in README)
- Official WireGuard Apple upstream: https://git.zx2c4.com/wireguard-apple
- PCRE2 API and resource limits: https://www.pcre.org/current/doc/html/pcre2api.html
- Bundled PCRE2 release: https://github.com/PCRE2Project/pcre2/releases/tag/pcre2-10.49
- LocalDevVPN product description, local tunnel scope: https://apps.apple.com/nz/app/localdevvpn/id6755608044
- Apple's App Store Server Library for Python: https://github.com/apple/app-store-server-library-python

No third-party VPN gateways were selected or claimed to be operational. Streaming compatibility, anonymity, throughput and uptime have not been measured.
